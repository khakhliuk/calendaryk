# Calendaryk

Telegram Mini App для репетиторів і викладачів: розклад занять, облік відвідуваності та оплачених уроків.

Вчитель запрошує учнів посиланням, складає для них регулярний розклад або разові заняття, відмічає, чи відбулося заняття, і веде нотатки. Учень бачить свій розклад і контакти викладача.

## Стек

- Vue 3 (Composition API, `<script setup>`) + TypeScript
- Vite
- PrimeVue 4, Tailwind CSS
- vue-cal - календар
- Supabase - БД, авторизація, edge-функції
- vue-tg - інтеграція з Telegram Mini Apps
